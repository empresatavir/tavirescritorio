Primeiros passos do servidor

Depois de instalar, faça este setup uma vez. Verde é pronto; âmbar é pendente. O que dá para automatizar já está em “Requisitos da máquina”; o resto são credenciais suas.

  1. Login da assinatura — os agentes usam a sua conta do Claude. Sem este login eles faltam com “not logged in”.
  2. Token do Jira — cadastre o Personal Access Token na aba Credenciais.
  3. Banco SQLite — o arquivo é criado na primeira subida. Não é um serviço à parte.
  4. Iniciar o servidor — o Node sobe dentro do Electron e abre a porta HTTP.
  5. Túnel público (opcional) — só se for expor o servidor fora desta máquina.

Banco de dados

SQLite, arquivo local do Concierge. Electron é a janela. Node é o processo que abre a porta e cuida das tabelas. Não há MySQL neste projeto.

Servidor

Liga o servidor para os clientes remotos: sobe o Node, lendo o SQLite, e abre a porta HTTP. Sem isso, o app funciona só como console local.

Orquestrador dos agentes de refinamento e desenvolvimento — para qualquer projeto.

v1.0.0-alpha.2

Objetivo

Acelerar e padronizar o ciclo das issues de qualquer projeto da empresa: acompanhar o board do Jira, refinar a causa-raiz no fonte, codificar a correção e compilar — com governança (nada é escrito no Jira sem o seu aceite) e sem sair da sua máquina. A ideia é você orquestrar os agentes como um concierge orquestra o atendimento: tudo no lugar, no seu comando. O Concierge nasceu no projeto VHF, mas foi pensado para atender qualquer produto/equipe.

Concierge

O concierge é quem orquestra e atende tudo que o hóspede precisa. Aqui, o app orquestra os agentes e cuida do fluxo de trabalho do time, seja qual for o projeto.

Íris

Na mitologia, Íris é a mensageira que liga os mundos (o arco-íris). Íris é também a parte do olho que enxerga. Nome curto e elegante para a assistente que vê os dados do projeto e te traz as respostas. Ela pensa com o Claude, usando a sua assinatura. Está preparada para um servidor próprio com Ollama.
