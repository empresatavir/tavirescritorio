# Fontes oficiais

- [Playwright Best Practices](https://playwright.dev/docs/best-practices) — comportamento visível ao usuário, isolamento, locators por role e assertions com espera.
- [Playwright Writing Tests](https://playwright.dev/docs/writing-tests) — estrutura de testes e assertions.
- [Playwright Test Reporters](https://playwright.dev/docs/test-reporters) — reporter HTML e artefatos de execução.
- [Playwright Trace Viewer](https://playwright.dev/docs/trace-viewer) — snapshots de ações, timeline, screenshots, console/rede e retenção de traces.
- [Playwright API Testing](https://playwright.dev/docs/api-testing) — testes diretos de API, preparação/pós-condição seguras e distinção em relação às ações no browser.
- [Playwright Locators](https://playwright.dev/docs/locators) — estratégias de locator voltadas ao usuário e interações resilientes.

A integração Mobile-MCP não é fixada a uma API externa: a autoridade para a versão instalada é `.agents/skills/mobile-mcp/SKILL.md` do projeto e os schemas das ferramentas disponíveis na sessão. Leia-os antes das ações em dispositivo.
