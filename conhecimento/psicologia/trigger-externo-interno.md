# Trigger Externo e Interno

## Definição
Trigger é o estímulo que inicia um comportamento. Existem dois tipos: **externos** (informação no ambiente que diz ao usuário o que fazer a seguir) e **internos** (associações aprendidas e armazenadas na memória, geralmente estados emocionais negativos, que ativam o comportamento automaticamente).

## Mecanismo

**Triggers externos** carregam informação explícita sobre a próxima ação. Classificam-se em quatro subtipos:
- *Paid*: anúncios pagos — eficazes para aquisição, insustentáveis para retenção
- *Earned*: cobertura de mídia, viralização — imprevisíveis e temporários
- *Relationship*: indicação de pessoa para pessoa — alta conversão, escala difícil
- *Owned*: ícone no celular, newsletter opt-in, push notification — o único tipo que funciona para retenção habitual

**Triggers internos** são estados emocionais que o usuário associa ao uso do produto após repetição suficiente (semanas a meses). Emoções negativas dominam: tédio → Twitter, solidão → Facebook, ansiedade de perder momento → Instagram, medo de estar fora do loop → email. A severidade do desconforto pode ser subliminar — o usuário não percebe conscientemente, mas age.

O objetivo do Hook Model é migrar o usuário de triggers externos para internos: quando isso ocorre, o produto dispensa publicidade e vira comportamento automático.

**O método dos 5 Porquês** é a ferramenta para descobrir o trigger interno real:
> Por que o usuário usa o email? → Para receber mensagens → Para saber o que está acontecendo → Para saber se alguém precisa dela → **Porque tem medo de estar fora do loop.**

A quinta resposta quase sempre revela uma emoção — esse é o trigger interno.

## Aplicações Práticas

### Em Produto / UX
- Projete owned triggers (notificações, emails) para disparar *no momento exato* em que o trigger interno naturalmente ocorre. Se o app é sobre produtividade pós-reunião, dispare a notificação quando o calendário indica que a reunião terminou (como o Any.do faz).
- Nunca peça opt-in para owned triggers antes de o usuário ter experimentado valor — ele não tem razão para aceitar.
- Mapeie o trigger interno com user narratives: "Toda vez que o usuário sente [emoção], ele [ação]." Essa frase deve orientar toda a estratégia de triggers.

### Em Marketing / Copy
- Emails de reativação que tocam no trigger interno convertem mais do que emails que falam do produto. "Está perdendo o fio das suas finanças?" é mais poderoso do que "Volte ao Mint".
- Subject lines que evocam a emoção negativa do trigger interno têm higher open rates — não pelo sensacionalismo, mas pela relevância emocional.

### Em Vendas
- A pergunta "O que te fez buscar uma solução agora?" aponta para o trigger interno do comprador. Usar essa linguagem no pitch cria identificação imediata.

## Contra-indicações
- Triggers externos excessivos destroem a relação: push notifications irrelevantes geram churn. O owned trigger só funciona se há valor percebido em cada disparo.
- Explorar triggers internos de dor aguda (ansiedade, depressão) para criar dependência é antiético — ver [[manipulation-matrix]].
- Triggers internos demoram semanas a meses para se formar — não existe atalho. Produto sem valor real nunca forma trigger interno.

## Exemplos Canônicos
- **Instagram**: trigger interno = medo de perder um momento especial. O usuário sente urgência, abre o app antes mesmo de formular o pensamento conscientemente.
- **Email**: trigger interno = ansiedade de estar fora do loop / necessidade de validação da própria importância.
- **Google**: trigger interno = incerteza / necessidade de resolver uma dúvida. "A primeira solução que vem à mente vence."
