# Biblioteca de referências de design

Fonte própria de referência dos agentes de design (Marina, Yuri) na Fábrica. Vem antes da busca na internet.

- `marketing/<nome>/` para LP e oferta; `produto/<nome>/` para sistema.
- Cada referência tem `card.md` (leitura), `medidas.json` (o que o Escritório mediu) e as telas `desktop.jpg` e `celular.jpg` (ficam só neste computador, fora do git).
- Capturar: `npm run design:ref -- https://site.com --familia marketing --nicho "clínica"`.
- Listar: `npm run design:ref -- --listar`.
- O card nasce como `status: rascunho`. Só vai para o kit dos agentes depois que o Carlos preencher a seção "Leitura" e trocar para `status: validado`. Agente não valida referência.
- Vale a estrutura (layout, ritmo, escala, densidade). Imagem, logo e texto do site não vão para projeto de cliente.
