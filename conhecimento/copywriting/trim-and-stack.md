# Trim & Stack — Criação da Grand Slam Offer

## Definição
Trim & Stack é o processo de 5 passos de Hormozi para construir uma Grand Slam Offer a partir do zero: partir do resultado sonhado do cliente, listar todos os problemas que impedem esse resultado, converter problemas em soluções, criar múltiplos veículos de entrega para cada solução, e então trimmar (cortar) os de baixo valor para empilhar (stack) apenas os de alto valor e baixo custo.

## Mecanismo

**Passo 1 — Identificar o Dream Outcome**
O cliente não compra o serviço. Ele compra o resultado. Não venda o voo, venda as férias. "Emagrecer 9kg em 6 semanas" é um dream outcome; "academia com personal trainer" não é.

**Passo 2 — Listar todos os problemas**
Para cada coisa que o cliente precisa fazer para alcançar o resultado, listar todos os problemas nos 4 eixos da [[valor-equation]]:
- *Dream outcome*: "isso não vai valer financeiramente"
- *Likelihood*: "não vai funcionar para mim especificamente"
- *Effort*: "vai ser muito difícil, vou odiar, não vou conseguir"
- *Time*: "vai demorar demais, sou muito ocupado"

Exercício de emagrecimento: comprar comida saudável + cozinhar + comer saudável + exercitar + manter a consistência → cada etapa tem 4-6 sub-problemas. Total: 32-64 problemas. Cada problema não resolvido pode ser a razão pela qual alguém não compra.

**Passo 3 — Transformar problemas em soluções**
Reverter cada problema em linguagem de solução: "cozinhar é caro" → "Como comer saudável por menos do que sua conta atual de mercado." Essa lista se torna o checklist do que a oferta precisa resolver.

**Passo 4 — Criar veículos de entrega**
Para cada solução, listar todas as formas possíveis de entregá-la, usando os eixos:
- *Nível de atenção*: 1-on-1, pequeno grupo, 1-para-muitos
- *Nível de esforço do cliente*: DIY (faça você), DWY (fazemos juntos), DFY (fazemos por você)
- *Meio de entrega*: presencial, por telefone, email, texto, Zoom, gravação, checklist

Objetivo: pensar divergentemente. 1 problema pode ter 15+ formas de ser resolvido. Ao final deste passo, existe uma lista enorme de possibilidades.

**Passo 5 — Trim & Stack**
Analisar custo vs. valor de cada item:
- **Eliminar**: alto custo, baixo valor
- **Eliminar**: baixo custo, baixo valor
- **Manter**: alto valor, baixo custo → **priorizar esses**
- **Manter**: alto valor, alto custo → incluir apenas onde o valor justifica

O alvo é o item "1-para-muitos" de alto valor: algo que custa muito para criar uma vez, mas escala infinitamente. Uma planilha de cálculo nutricional, um tour gravado no supermercado, um script de vendas testado — alto custo de criação, custo marginal de distribuição zero.

**Resultado final — o bundle enumerado:**
Listar cada item do stack com: nome específico com benefício no título + valor atribuído em dinheiro. Exemplo de bundle para academia:
- Sistema de Compras Inteligentes (valor: $1.000)
- Guia de Refeições em 5 Minutos (valor: $600)
- Plano de Refeições Personalizado (valor: $500)
- Treinos Queima-Gordura Comprovados (valor: $699)
- ...
- Total percebido: $4.351 — por apenas $599

## Aplicações Práticas

### Em Vendas
O bundle enumerado transforma o pitch. Em vez de "oferecemos acompanhamento nutricional", você apresenta cada item individualmente com nome, valor e como resolve uma objeção específica. A soma dos valores percebidos é muito maior que o preço cobrado.

### Em SaaS / Produto
Mapear todos os problemas que impedem o cliente de usar o produto com sucesso — e resolver cada um como parte da oferta. Onboarding, suporte, templates, documentação, comunidade, consultoria inicial — tudo pode ser enumerado e valorizado.

### Em Marketing / Copy
A lista de problemas → soluções vira o script de copy. Cada item do stack aborda uma objeção específica. Uma landing page que enumera e valoriza 8 componentes da oferta converte mais do que uma que descreve a oferta como um todo.

## Contra-indicações
Não adicionar itens ao stack para impressionar — cada item deve resolver um problema real percebido pelo avatar. Stack inflado com itens de baixo valor dilui a percepção dos itens de alto valor. Hormozi: "só precisas fazer isso uma única vez para um produto que pode durar anos."

## Exemplos Canônicos
- **Bundle de academia de Hormozi**: de membership a $99/mês para bundle $599 → $2.400-$5.200 com o mesmo serviço core, adicionando soluções para cada problema do caminho.
- **Gym Launch done-for-you → done-with-you**: mesma promessa ("encherei sua academia em 30 dias"), mudou apenas o veículo de entrega (presencial → remoto) → escalou de 8 gyms/mês para centenas.
