# Framework da Irracionalidade Previsível

## Definição

O framework de Ariely organiza os principais vieses comportamentais humanos em categorias de erros sistemáticos e previsíveis — com implicações diretas para design de produtos, pricing, marketing e políticas públicas. A premissa central: irracionalidade não é aleatória, é arquitetável.

## Tese Central

Enquanto a economia clássica assume racionalidade como premissa, Ariely demonstra empiricamente que:

1. Nossas decisões são sistematicamente irracionais
2. Os padrões de irracionalidade são previsíveis e repetíveis
3. Forças externas invisíveis (preço, contexto, ordem, posse) moldam nossas escolhas mais do que nossas preferências conscientes
4. Portanto: quem entende esses padrões pode desenhar ambientes de escolha que guiam comportamentos — para o bem ou para o mal

## Como Usar o Framework

### Passo 1 — Diagnóstico
Identifique qual força está moldando o comportamento que você quer mudar (ou explorar):

- O usuário não converte? → [[ancoragem-arbitraria]] ou [[efeito-isca]]
- O trial não ativa? → [[efeito-zero-custo]] mal aproveitado ou onboarding fraco
- O cliente não renova? → [[efeito-posse]] não foi ativado; usuário não tem dados na plataforma
- O churn é alto? → [[normas-sociais-vs-mercado]] comprometidas; relação é transacional demais
- O ticket médio é baixo? → [[efeito-placebo-preco]]; preços baixos = menos comprometimento
- Leads não decidem? → [[manutencao-de-opcoes]]; sem deadline real

### Passo 2 — Intervenção
Desenhe o ambiente de escolha para usar a força corretamente:

- **Relatividade**: sempre mostre o contexto de comparação que favorece sua oferta
- **Zero**: use free trial, frete grátis, features gratuitas como porta de entrada
- **Social**: trate early adopters como parceiros (norma social), não clientes (norma mercado)
- **Posse**: faça o usuário carregar dados reais no onboarding o mais rápido possível
- **Deadlines**: crie urgência real (não artificial) para forçar fechamento de porta

### Passo 3 — Verificação Ética
O framework pode ser usado para o bem ou para o mal. Checklist:

- A intervenção ajuda o usuário a tomar uma decisão que ele quer tomar?
- Ou manipula o usuário para uma decisão que o prejudica?
- A transparência sobre o mecanismo destruiria o efeito?

Se a resposta à terceira pergunta é "sim, a transparência destruiria o efeito", a intervenção é manipulação — não design comportamental ético.

## Contraste com Frameworks Relacionados

| Framework | Foco | Nível |
|---|---|---|
| Ariely (Predictably Irrational) | Decisões individuais em mercados | Micro (interação) |
| Kahneman (Sistema 1 e 2) | Processamento cognitivo dual | Cognitivo (mecanismo) |
| Cialdini (7 Princípios) | Influência interpessoal | Relacional |
| Fogg (BM) | Comportamento em produto | Design de produto |
| Nir Eyal (Hook) | Formação de hábito | Loop de produto |

Ariely e Kahneman são complementares: Kahneman explica *por que* os vieses existem (Sistema 1 vs. 2); Ariely demonstra *como* se manifestam em decisões concretas de consumo e design.
