# Manipulation Matrix

## Definição
Ferramenta de decisão ética para criadores de produtos que formam hábito. Cruza duas perguntas — "o criador usaria o produto?" e "o produto melhora materialmente a vida do usuário?" — gerando quatro arquétipos que ajudam a responder: não "posso criar este hábito?" mas **"devo criar este hábito?"**

## Mecanismo

A matriz tem dois eixos:

**Eixo X:** O criador usa o produto? (Sim / Não)
**Eixo Y:** O produto melhora materialmente a vida do usuário? (Sim / Não)

Isso gera quatro quadrantes:

```
                  Melhora a vida do usuário
                         Sim        Não
                   ┌──────────┬──────────┐
O criador usa  Sim │Facilitador│Entretene-│
o produto?         │          │dor       │
               Não │ Vendedor │  Dealer  │
                   └──────────┴──────────┘
```

**Facilitador** (usa + melhora): a zona ética. O criador experimenta o mesmo problema que resolve. Exemplos: fundadores do Twitter e Instagram criando conexão social que eles mesmos queriam. Nuru International criando hábitos agrícolas porque o fundador viveu a pobreza que combate.

**Peddler / Vendedor** (não usa + melhora): intenção genuína de ajudar, mas desconexão com o usuário. Apps de saúde criados por pessoas que não têm o problema de saúde que visam resolver. Campanhas de gamificação de tarefas que ninguém quer fazer. Alta chance de falhar por falta de empatia real — não por má intenção.

**Entertainer / Entretedor** (usa + não melhora materialmente): entretenimento puro — válido como arte, mas de vida curta. FarmVille, Angry Birds, hit songs. Negócio de hits: requer pipeline constante de novidade porque o produto é finito. O criador genuinamente gosta do que faz, mas não pode alegar que melhora vidas.

**Dealer** (não usa + não melhora): exploração pura. Criar dependência para extrair dinheiro sem benefício real ao usuário. Casinos que visam compulsivos, dark patterns que maximizam lifetime value destruindo qualidade de vida. "Se você não usaria, e não acredita que melhora a vida deles, o único motivo é lucro às custas deles."

**A zona cinza:** criadores honestos às vezes se enganam. Teste: "Preciso qualificar ou justificar minha resposta?" — se sim, você falhou. A resposta deve ser imediata e honesta. Outra forma: "Eu usaria isso na minha versão mais jovem/diferente?" — funciona para produtos educacionais.

**Responsabilidade adicional:** mesmo facilitadores devem monitorar usuários com dependência patológica. Estimativas: 1% dos usuários de tecnologias mais viciantes desenvolvem dependência prejudicial. As empresas têm acesso a dados que podem identificar esses usuários — a obrigação moral é agir.

## Aplicações Práticas

### Para Founders / PMs
- Aplique a matriz *antes* de escrever uma linha de código. "Devo construir isso?" antecede "posso construir isso?"
- Revise a matriz a cada pivô de produto ou nova feature de engajamento. Um produto facilitador pode deslizar para dealer com features mal planejadas.
- Mantenha canais de feedback para identificar usuários com sinais de uso compulsivo prejudicial — e tenha protocolo para agir.

### Para Investidores / Stakeholders
- Use a matriz como due diligence ética: o fundador usaria o produto? (Se não usa, red flag de empatia.) O produto tem mecanismo claro de melhoria de vida além do engajamento?
- Produtos na zona dealer têm risco regulatório crescente — vide debates sobre social media, gambling, loot boxes em jogos.

### Para Agências / Consultores
- Ao propor estratégias de engajamento para clientes, aplique a matriz antes de apresentar. Recomendar dark patterns que maximizam métricas de vaidade enquanto prejudicam usuários é posição indefensável eticamente e juridicamente.

## Contra-indicações
- A matriz é uma heurística, não um julgamento definitivo. "Melhorar materialmente a vida" é subjetivo — não há resposta objetiva para todo caso.
- Facilitadores não têm carta branca para qualquer tática de engajamento — o fato de o produto ser bom não justifica manipulação de usuários vulneráveis.
- Entertainer não é necessariamente ruim — arte e entretenimento têm valor intrínseco. A matriz apenas alerta para os limites do modelo de negócio.

## Exemplos Canônicos
- **Weight Watchers** (Facilitador): sistema de controle alimentar que os próprios usuários escolhem conscientemente, com resultados mensuráveis de melhora de saúde.
- **Cow Clicker** (Dealer/Arte): Ian Bogost criou ironicamente para satirizar FarmVille — utilizava os mesmos dark patterns de forma explícita. Quando usuários se tornaram genuinamente obsessivos, Bogost encerrou o serviço ("The Cowpocalypse").
- **Apps de gamificação de tarefas odiadas** (Peddler): designers que nunca precisaram fazer aquela tarefa, criando badges e pontos que não aliviam trigger interno real.
