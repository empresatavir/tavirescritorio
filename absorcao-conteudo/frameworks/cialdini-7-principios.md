# Os 7 Princípios de Influência de Cialdini

## Definição
Framework que mapeia os sete atalhos cognitivos universais que o cérebro usa para tomar decisões rápidas de concordância ou discordância. Cada princípio é um "klick & ab" (clique e vai) — um sinal que, quando presente, ativa uma resposta automática de obediência ou resistência. Cialdini construiu o framework em 3 anos infiltrado em ambientes de vendas, marketing e fundraising, depois validou em décadas de pesquisa experimental.

## O Framework

```
┌─────────────────────────────────────────────────────────────────┐
│          OS 7 PRINCÍPIOS DE INFLUÊNCIA (CIALDINI 2021)          │
├──────────────────────┬──────────────────────┬───────────────────┤
│  PRINCÍPIO           │  GATILHO CENTRAL      │  VULNERABILIDADE  │
├──────────────────────┼──────────────────────┼───────────────────┤
│ 1. Reciprocidade     │ Receber um favor      │ Obrigação social  │
│ 2. Afinidade         │ Gostar de alguém      │ Halo effect       │
│ 3. Prova Social      │ "Outros fazem isso"   │ Incerteza         │
│ 4. Autoridade        │ Sinal de expertise    │ Obediência        │
│ 5. Escassez          │ Ameaça de perda       │ Aversão à perda   │
│ 6. Compromisso       │ Decisão anterior      │ Consistência      │
│ 7. Unidade/Wir       │ Identidade tribal     │ Fusão de "eu"     │
└──────────────────────┴──────────────────────┴───────────────────┘
```

## Mecanismo Central
O modelo parte de uma premissa: em um mundo de sobrecarga de informação, o cérebro precisa de atalhos. Processar cada decisão do zero seria insustentável. Os 7 princípios codificam sinais ambientais que, na maioria dos contextos evolutivos, levavam a decisões corretas:

- **Reciprocidade**: retribuir favores mantinha alianças vitais
- **Afinidade**: preferir pessoas similares selecionava parceiros confiáveis
- **Prova Social**: seguir o grupo economizava processamento individual em incerteza
- **Autoridade**: obedecer a especialistas aproveitava conhecimento acumulado
- **Escassez**: agir rápido ante recursos raros evitava perdas reais
- **Compromisso**: ser consistente construía reputação e facilitava previsibilidade social
- **Unidade**: favorecer o grupo próprio maximizava a sobrevivência coletiva de genes compartilhados

O problema moderno: esses atalhos foram calibrados para ambientes ancestrais. Em mercados modernos, os mesmos sinais podem ser fabricados — e quando o sinal é falso, o atalho leva a decisões erradas.

## Os 7 Princípios em Detalhe

### 1. [[reciprocidade]] — importância 9/10
Quando alguém nos dá algo, sentimos obrigação de retribuir. Opera independentemente de gostarmos de quem deu. A obrigação pesa mesmo com presentes não solicitados. **Técnicas**: presentes grátis, amostras, conteúdo de valor, concessões em negociação (door-in-the-face). **Risco**: sentimento de manipulação quando o presente é percebido como isca.

### 2. [[afinidade]] — importância 7/10
Dizemos sim mais facilmente para quem gostamos. Vetores: atratividade física, similaridade, familiaridade (mera exposição), associação positiva, cooperação. **Diferença de [[unidade-gemeinschaft]]**: afinidade é "como eu" (similaridade); unidade é "um de nós" (identidade). **Técnicas**: rapport, espelhamento, associação de marca, storytelling pessoal.

### 3. [[prova-social]] — importância 10/10
Em incerteza, observamos o comportamento de outros similares e usamos como evidência do correto. Amplificado por: incerteza alta, número de pessoas, e sobretudo similaridade ("pessoas *como eu* fazem isso"). **Perigo**: prova social negativa (mostrar que muitos fazem o indesejado *aumenta* o comportamento). **Efeito Werther**: suicídios aumentam após notícia de suicídio de figura similar.

### 4. [[autoridade]] — importância 8/10
Seguimos especialistas e figuras de autoridade mesmo sem verificar qualificação real. Símbolos: títulos, roupas/uniforme, distintivos. Credibilidade = expertise + confiabilidade. **Técnica Warren Buffett**: admitir fraquezas antes de apresentar pontos fortes multiplica a confiança nas afirmações subsequentes.

### 5. [[escassez]] — importância 9/10
Oportunidades parecem mais valiosas quando limitadas. Dois mecanismos independentes: Verlustaversion ([[aversao-a-perda|perda pesa 2x mais que ganho equivalente]] — Kahneman) e Reativância Psicológica ([[reativancia-psicologica]] — Brehm: quando liberdade é ameaçada, o item proibido fica mais desejável). Escassez recém-criada > escassez permanente. Competição amplifica.

### 6. [[compromisso-consistencia]] — importância 9/10
Após tomar uma posição, há pressão para agir consistentemente com ela. O compromisso se autossustenta: quem se compromete constrói novas razões que justificam o compromisso, mesmo quando a condição original muda ([[low-ball]]). Amplificadores: ativo > passivo, público > privado, escrito > oral, e sobretudo **interno** (sem pressão externa) > externo.

### 7. [[unidade-gemeinschaft]] — importância 9/10
O 7º princípio, adicionado em 2021. Membros do "Wir" (nós) recebem generosidade, confiança e cooperação automaticamente aumentadas. Diferente de afinidade: não é "parecido comigo" mas "um de nós" — identidade tribal compartilhada. Gerado por: pertencimento (família, origem, lugar) e ação conjunta (sincronização, música, sofrimento compartilhado, co-criação).

## Neidert's Core Motives Model — Qual Princípio Usar Quando

Framework do Dr. Gregory Neidert que organiza os 7 princípios por *objetivo de persuasão*. O persuasor nem sempre precisa usar todos os princípios — precisa usar os certos para o objetivo certo:

```
┌─────────────────────────────────────────────────────────────────┐
│              CORE MOTIVES MODEL (NEIDERT / CIALDINI 2021)        │
├──────────────────────┬──────────────────────────────────────────┤
│  OBJETIVO            │  PRINCÍPIOS PRIORITÁRIOS                  │
├──────────────────────┼──────────────────────────────────────────┤
│ 1. Cultivar relação  │ Reciprocidade + Afinidade + Unidade       │
│ 2. Reduzir incerteza │ Prova Social + Autoridade                 │
│ 3. Motivar ação      │ Compromisso + Escassez                    │
└──────────────────────┴──────────────────────────────────────────┘
```

**Sequência importa:** A relação positiva precede a redução de incerteza, que precede a motivação para ação. Usar escassez antes de estabelecer relação é uma inversão que frequentemente fracassa — a urgência sem confiança parece manipulação.

**Exemplo aplicado**: sequência ótima de uma campanha de SaaS:
1. Conteúdo gratuito de valor (reciprocidade) + comunicação próxima (afinidade) → relação
2. Case studies de empresas similares (prova social) + credenciais do fundador (autoridade) → incerteza reduzida
3. Trial limitado ou desconto por tempo (escassez) + onboarding com micro-compromissos (compromisso) → ação

## Como os Princípios Interagem

Os 7 princípios não operam em isolamento — combinações são multiplicadores:

| Combinação | Efeito |
|---|---|
| Prova Social + Similaridade | Mais poderoso que prova social isolada |
| Autoridade + Afinidade | Especialista de quem gostamos — máxima credibilidade |
| Escassez + Prova Social | "Todos querem" + "pouco disponível" = urgência máxima |
| Reciprocidade + Unidade | Dentro do Wir, a obrigação de retribuir é mais intensa |
| Compromisso + Público | Compromisso escrito e público é o mais duradouro |

## Uso Ético vs. Exploração

Cialdini distingue três posições:
- **Uso ético**: o sinal ativado é real. O produto é genuinamente escasso; a autoridade é genuína; a prova social é de usuários reais.
- **Exploração**: o sinal é fabricado. Reviews compradas, escassez artificial, autoridade inventada.
- **Defesa**: reconhecer quando os princípios estão sendo usados permite tomar decisões mais deliberadas. "Se eu soubesse disso desde o início, decidiria da mesma forma?"
