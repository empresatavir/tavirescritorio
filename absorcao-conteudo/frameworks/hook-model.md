# Hook Model

## Definição
Framework de quatro fases — Trigger → Action → Variable Reward → Investment — que, repetido sucessivamente, converte comportamentos conscientes em hábitos automáticos, associando o uso do produto a estados emocionais internos do usuário.

## Mecanismo

O ciclo funciona porque cada fase prepara o terreno para a próxima:

1. **Trigger** — um estímulo externo (notificação, ícone, email) ou interno (tédio, solidão, medo) inicia o comportamento. O objetivo final é que triggers externos se tornem desnecessários — o usuário age a partir de triggers internos.

2. **Action** — a ação mais simples possível em antecipação a uma recompensa. Quanto menor o esforço (cognitivo, físico, temporal), maior a probabilidade da ação ocorrer. Baseia-se no modelo B = MAT de Fogg: Behavior = Motivation × Ability × Trigger.

3. **Variable Reward** — recompensa variável e imprevisível que suprime as áreas de julgamento do córtex pré-frontal e ativa o sistema de dopamine. A variabilidade é o que cria o craving — não a recompensa em si, mas a *antecipação* dela. Três tipos: Tribe (social), Hunt (recursos/informação), Self (maestria).

4. **Investment** — o usuário deposita esforço no produto (dados, conteúdo, seguidores, habilidade). Isso aumenta o valor percebido pelo usuário e carrega o próximo trigger externo, reiniciando o ciclo.

A distinção crítica entre Hook Model e um feedback loop comum: o investimento torna cada ciclo mais valioso do que o anterior. O produto melhora com o uso — e o custo de abandono cresce.

## Aplicações Práticas

### Em SaaS / Produto
- Mapeie cada fase do hook para seu produto: qual é o trigger interno do usuário? Qual é a menor ação que ele pode tomar? Qual recompensa ele recebe? O que ele deixa no produto?
- Optimize a fase de Action primeiro — remova passos desnecessários antes de tentar aumentar motivação.
- Projete investments progressivos: peça pouco no início (email, primeira preferência) e aumente o investimento à medida que o hábito se forma.
- Use o Investment para carregar o próximo trigger: ao completar uma ação, o produto deve agendar ou provocar o retorno (ex.: Snapchat — cada foto enviada é um convite implícito à resposta).

### Em Marketing / Copy
- Mensagens de reativação devem atacar o trigger interno, não o produto ("Sentiu falta de algo?" vs. "Volte ao produto X").
- Onboarding deve guiar o usuário pelo primeiro ciclo completo do hook rapidamente — o primeiro loop é o mais crítico.
- Gamificação sem hook real não funciona: pontos e badges só engajam se resolverem um trigger interno genuíno.

### Em Vendas
- O vendedor que entende o trigger interno do comprador negocia melhor. "O que te faz voltar a este problema toda semana?" revela o internal trigger.
- Produtos com hook forte têm maior CLTV, menor churn e maior pricing power — argumento direto com investidores.

## Contra-indicações
- Produtos de uso infrequente e alta utilidade (seguro de vida, software de declaração de IR) não se beneficiam do Hook Model — não exigem hábito.
- Construir o hook antes de validar que o produto resolve uma dor real é desperdício. O hook amplifica um produto bom e acelera a queda de um ruim.
- Usar o hook para criar dependência de algo que não beneficia o usuário é antiético — ver [[manipulation-matrix]].

## Exemplos Canônicos
- **Instagram**: trigger interno (medo de perder um momento) → action (abrir app + fotografar) → variable reward (likes, comentários imprevisíveis) → investment (seguidores acumulados, biblioteca de fotos).
- **Twitter**: trigger (tédio/FOMO) → action (scroll) → variable reward (tweet relevante entre conteúdo mundano) → investment (seguir pessoas, acumular seguidores).
- **Email**: trigger (ansiedade de estar fora do loop) → action (abrir inbox) → variable reward (quem me escreveu? o que há de novo?) → investment (responder, organizar, arquivar).
