# Natural Planning Model

## Definição
O Natural Planning Model (NPM) é o processo de 5 fases que o cérebro usa naturalmente ao planejar qualquer coisa — desde jantar fora até lançar uma empresa. Contrasta com o "Unnatural Planning" (planejamento artificial) que a maioria das pessoas e organizações usa, que começa pelas etapas erradas e gera projetos travados. Quando as 5 fases são aplicadas conscientemente e na ordem correta, qualquer projeto move-se de confusão para clareza e ação.

## Mecanismo

### As 5 Fases em Ordem

**1. Propósito e Princípios (WHY)**

Por que você está fazendo isso? Qual é o propósito fundamental que justifica o projeto?

A pergunta "por que?" não é filosófica — é operacional. O propósito:
- *Define sucesso*: sem saber o porquê, você nunca sabe quando está "pronto"
- *Cria critérios de decisão*: perguntas sobre recursos, escopo e prioridade só têm resposta quando o propósito está claro
- *Alinha pessoas*: em times, o propósito compartilhado resolve conflitos sobre como fazer
- *Expande opções*: paradoxalmente, clareza de propósito abre mais possibilidades, não menos

Princípios são os parâmetros de comportamento dentro dos quais o projeto deve operar ("não gastamos mais de X", "mantemos qualidade Y", "respeitamos o prazo Z").

**2. Visão de Resultado (WHAT)**

Como será o mundo quando o projeto estiver completo com sucesso total? Imaginar detalhadamente — visualmente, sensorialmente — o estado final desejado.

O Sistema Ativador Reticular (SAR) no cérebro filtra informação com base no que está focando. Quando você se compromete com uma imagem clara de sucesso, o cérebro começa automaticamente a notar informações relevantes que antes ignorava. Isso não é "lei da atração" — é neurologia básica de filtragem atencional.

A técnica: "Imagine Wild Success" — projete-se para além da data de conclusão e descreva em detalhes o que seria o sucesso total. Suspenda "yeah, but..." temporariamente.

**3. Brainstorming (HOW)**

Uma vez que o propósito e a visão estão claros, o cérebro começa naturalmente a preencher os gaps entre "onde estamos" e "onde queremos chegar". Isso é brainstorming — a fase criativa.

As 3 regras do brainstorming eficaz:
- **Não julgar, não avaliar**: capturar tudo sem filtro imediato
- **Quantidade sobre qualidade**: mais ideias = maior contexto para selecionar depois
- **Análise em segundo plano**: o objetivo desta fase é expansão, não contração

"Distributed cognition" — ao externalizar ideias (papel, whiteboard, notas), o cérebro recebe de volta os pensamentos e gera mais. Tentar fazer brainstorming "só na cabeça" é limitado pela capacidade de RAM de curto prazo.

**4. Organização (STRUCTURE)**

Depois de gerar um volume suficiente de ideias, padrões naturais emergem. Essa fase organiza o brainstorm em:
- **Componentes**: as partes principais do projeto
- **Sequências**: a ordem em que as coisas precisam acontecer
- **Prioridades**: o que é crítico vs. o que é desejável

Isso não exige software de gerenciamento de projetos para 80% dos projetos — um envelope e uma caneta fazem o trabalho. Formalidade excessiva nessa fase é um bloqueio, não uma ajuda.

**5. Próximas Ações (NEXT ACTIONS)**

A última fase: o que concretamente precisa acontecer agora para mover o projeto?

Para cada "parte móvel" do projeto que pode avançar hoje (sem depender de outra parte ser concluída primeiro), deve existir uma próxima ação definida. Isso inclui ações de *planejamento* — se ainda há mais planejamento a fazer, a próxima ação é "Draft ideias sobre X" ou "Agendar reunião para definir Y".

### O Unnatural Planning (Por Que Projetos Travam)

O modelo reativo que a maioria usa é o inverso:

```
Problema → Ação urgente → Reorganização → Brainstorming → "Qual o objetivo?"
```

Sintomas de unnatural planning:
- Reuniões que começam com "quem tem uma boa ideia?"
- Planos criados depois do fato para "agradar às autoridades"
- Projetos que precisam de outra reunião para definir o que foi decidido na primeira
- Projetos que só evoluem quando a crise força ação

### Quanto Planejamento É Necessário?

A resposta de Allen: tanto quanto necessário para o projeto sair da sua mente.

- **~80% dos projetos**: precisam apenas de outcome definido + próxima ação. Nenhum planejamento formal necessário
- **~15% dos projetos**: precisam de alguma estrutura externa (mind-map, bullet points, notas)
- **~5% dos projetos**: merecem aplicação explícita e deliberada das 5 fases

Indicador de que é preciso mais planejamento: o projeto ainda está na sua mente depois de definir a próxima ação.

## Aplicações Práticas

### Para Novos Projetos
- Antes de começar qualquer projeto: 2 minutos respondendo "por que estamos fazendo isso?"
- Depois: imaginar o resultado com sucesso em detalhes específicos
- Só então: brainstorm livre de como chegar lá

### Para Projetos Travados
- Se um projeto não está avançando, diagnosticar em qual fase está preso:
  - Sem progresso de ação → precisa de mais organização ou planejamento
  - Sem clareza no planejamento → precisa de mais brainstorming
  - Brainstorming não flui → precisa de visão mais clara do resultado
  - Visão não se materializa → propósito não está claro o suficiente

### Para Reuniões de Planejamento
- Começar toda reunião de planejamento com: "Qual é o propósito desta reunião? Como saberemos que foi bem-sucedida?"
- Reservar tempo para brainstorming genuíno antes de avaliação
- Terminar com: "Quais são as próximas ações, e quem as tem?"

### Relação com Other Frameworks

O NPM mapeia diretamente sobre outros frameworks do vault:
- [[7-perguntas-negocio-thiel]]: as 7 perguntas são uma versão do NPM para negócios — Propósito (por que existe?), Visão (onde vai chegar?), Brainstorming (quais são as opções de execução?), e Próximas Ações (what's the team? the distribution? the timeline?)
- [[otimismo-definido]] de Thiel: o "outcome visioning" do NPM é a prática operacional do otimismo definido — ter uma imagem clara e específica do futuro desejado

## Contra-indicações
- Aplicar as 5 fases formalmente a tudo é excessivo — a maioria dos projetos usa só outcome + próxima ação
- O brainstorming sem propósito claro gera apenas listas de tarefas, não insights
- A fase de organização prematura (antes do brainstorming completo) filtra ideias úteis que ainda não apareceram

## Exemplos Canônicos
- **Jantar fora** (exemplo do livro): propósito (socializar, celebrar) → visão (ambiente X com pessoas Y) → brainstorm (onde? quem convidar? que hora?) → organizar (sequenciar: verificar disponibilidade → reservar → convidar) → próxima ação (ligar para o restaurante)
- **Business plan "de meses"**: participante de seminário fez um business plan em minutos usando o NPM explicitamente quando antes achava que levaria meses. "I don't know whether I should thank you or be angry."
