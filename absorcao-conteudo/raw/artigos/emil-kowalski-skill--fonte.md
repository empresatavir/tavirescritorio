# AI Skills for Design Engineers — Emil Kowalski

## Tese Central
"Taste" — o senso estético que separa uma interface medíocre de uma excelente —
não é um dom inato, é uma habilidade que se desenvolve e que pode ser transferida
para um agente de IA. A transferência funciona melhor com um vocabulário preciso
(palavras específicas para descrever movimento/animação, não "faz uma animação
legal") e com um ciclo de construir → revisar, não construir uma vez só.

## Por que é importante
Autor com credibilidade real no espaço (design engineer, autor de bibliotecas
JS usadas amplamente como Sonner e Vaul, patrocinador do [[taste-skill--fonte]]
— o mesmo Emil aparece nos dois lados). Complementa as outras 2 fontes: elas
descrevem O QUE verificar (checklists, regras por indústria); esta descreve
COMO desenvolver o julgamento que decide o que é bom ANTES de existir uma regra
escrita pra isso — a camada de critério, não só de processo.
