# Próxima Ação Física

## Definição
A "próxima ação física" é a próxima atividade física e visível que precisa acontecer para mover um projeto ou compromisso adiante. Não é um projeto, não é um resultado, não é uma intenção — é uma descrição de comportamento concreto: "Ligar para João para perguntar o número da oficina que ele recomendou." A pergunta "Qual é a próxima ação?" é o mecanismo central do GTD — e possivelmente a mais simples e mais poderosa ferramenta de produtividade que existe.

## Mecanismo

### Por Que Itens Ficam Travados

A maioria dos projetos não trava por falta de tempo ou de capacidade. Trava porque a próxima ação nunca foi claramente definida.

Exemplo canônico: "Pneus" em uma lista. O que isso significa? Quando você vê isso na lista, seu cérebro sabe que tem algo pendente mas não sabe *o que fazer agora*. Resultado: você ignora o item ou "rethink" mentalmente o mesmo projeto várias vezes sem progredir.

Quando a pergunta "Qual é a próxima ação física?" é feita explicitamente:
- "Preciso de pneus novos no carro."
- "Então qual é a próxima ação?"
- "Preciso ligar para uma borracharia. Mas não tenho o número."
- "Qual é a próxima ação para obter o número?"
- "O João recomendou uma. Preciso ligar para o João."
- Próxima ação: **"Ligar para João para obter número da borracharia que ele recomendou."**

Esse processo de rastreamento backwards até a ação física concreta geralmente revela 2-4 sub-passos que nunca foram explicitados. É nesses gaps que os projetos ficam presos.

### "Intelligently Dumbing Down"

Allen descreve um fenômeno fascinante: pessoas inteligentes procrastinam mais, não menos.

A razão: capacidade imaginativa maior = capacidade maior de gerar cenários negativos detalhados sobre um projeto. Ao pensar no imposto de renda, a pessoa inteligente não pensa "é só preencher um formulário" — ela pensa em toda a cadeia de implicações: formulários novos, documentação necessária, possíveis erros, possível auditoria, consequências legais... e entra em modo de fuga.

A solução é "intelligently dumb yourself down" — definir deliberadamente a próxima ação física concreta. Não pensar no projeto inteiro. Pensar apenas: *o que eu fisicamente faço primeiro?*

"Ligar para o contador" torna o item tão simples que a resistência desaparece. O cérebro percebe que é capaz de completar essa ação. A energia de resistência se dissolve.

### O Efeito sobre Motivação e Energia

Algo notável acontece quando a próxima ação física é definida: a energia aumenta imediatamente, mesmo que *nada no mundo real tenha mudado*. O projeto ainda existe, ainda é complexo, ainda vai requerer esforço. Mas a sensação subjetiva muda de "travado e esmagador" para "gerenciável e movível".

A explicação: o cérebro responde às imagens que você cria. Um projeto como "blob amorfo de undoability" (frase de uma cliente de Allen) gera paralisia. Uma ação concreta como "ligar para X sobre Y" gera um caminho claro — e o sistema nervoso responde com ativação ao invés de fuga.

### A Pergunta como Padrão Operacional

Allen tem uma missão pessoal declarada: tornar "Qual é a próxima ação?" parte do processo de pensamento global — em reuniões, conversas, projetos e interações de qualquer tipo.

O impacto quando isso se torna padrão operacional em uma organização:
- **Clareza**: reuniões terminam com decisões reais, não com "vamos seguir adiante"
- **Accountability**: fica claro quem tem o ball — e quem não tem
- **Produtividade**: ações são decididas quando os projetos surgem, não quando explodem
- **Empoderamento**: a pergunta pressupõe que algo *pode* ser feito. Destrói a mentalidade de vítima

Exemplo prático de Allen: ao facilitar reuniões, ele força a pergunta "qual é a próxima ação?" 20 minutos antes do fim. Invariavelmente há 20 minutos de clarificação necessária que não havia acontecido ainda.

### O Que NÃO é Uma Próxima Ação

Itens que frequentemente aparecem em listas mas não são próximas ações concretas:
- "Reunião com comitê de banquete" → não é uma ação, é um evento ou um projeto
- "Aniversário do Johnny" → não é uma ação, é um contexto
- "Assistente" → completamente ambíguo
- "Apresentação de slides" → é um projeto, não uma ação

O risco dessas entradas: quando você olha para elas, o cérebro entra em modo de reprocessamento (precisa descobrir o que fazer) em vez de modo de execução (executa o que já foi decidido). O sistema para de funcionar como uma lista de ações e vira uma lista de "coisas que ainda precisam de pensamento".

## Aplicações Práticas

### Em Reuniões
- Encerrar toda reunião com: "Quais são as próximas ações aqui? Quem as tem? Quando?"
- Uma reunião sem próximas ações definidas é uma reunião incompleta
- A pergunta revela se houve decisão real ou apenas discussão

### Em Revisão de Projetos
- Para cada projeto na lista: "Há uma próxima ação concreta definida para isso agora?"
- Se não há, o projeto está "travado" no sistema — precisa de uma próxima ação para se mover
- "Draft ideas sobre X" é uma próxima ação válida quando o próximo passo é mais pensamento

### Para Quebrar Procrastinação
- Quando você se descobre adiando algo: escreva explicitamente a próxima ação física mais pequena possível
- "Abrir o arquivo" conta como próxima ação se é isso que está te travando
- O objetivo é fazer o limiar de entrada tão baixo que a resistência não tem onde se ancorar

### No Contexto de Agência
- Para todo projeto de cliente: qual é a próxima ação física? Quem a tem? Para quando?
- Para todo item de backlog: é uma próxima ação ou um projeto que precisa de mais definição?
- A cultura de "qual a próxima ação?" é especialmente valiosa em times distribuídos onde o contexto não é compartilhado em tempo real

## Contra-indicações
- Definir próximas ações muito granulares cria overhead excessivo — "abrir email" não precisa estar na lista se "responder email de cliente X" já é suficientemente concreto
- A pergunta não substitui o planejamento — para projetos complexos, definir próximas ações sem o Natural Planning Model upstream gera ações sem direção
- Em contextos de alta urgência e crise, a pergunta pode ser usada depois — durante a crise, execute; depois, organize

## Exemplos Canônicos
- **Pneus**: "pneus" na lista vs. "ligar para João para número da oficina" — o segundo é executável imediatamente
- **Imposto de renda**: "fazer o IR" vs. "ligar para o contador para pegar lista de documentos necessários" — o segundo derruba a procrastinação
- **Reunião de board**: execução de uma reunião só começa quando "qual a próxima ação?" é perguntado ao final — caso de Allen facilitando reuniões
